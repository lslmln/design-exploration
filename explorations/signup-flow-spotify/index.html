Gap flagged: Spotify's own search-bar spec (white fill, 44pt, 6pt radius) and primary pill CTA (green, black text, full pill) are genuine matches — Spotify's app does have simple text-entry fields and a signature CTA button. But Spotify has no documented "continue with Google/Apple/Facebook" OAuth button component (its own account creation is handled by the OS-level Sign in with Apple / email, not a stack of third-party buttons), so Photoroom's social buttons are improvised from the outline-pill and filled-pill patterns rather than a real documented component. Woolworths' step progress bar is also invented — Spotify's only real progress bar is the playback scrubber, repurposed here at thinner scale.
Font substitution: Spotify Mix is proprietary and not bundled here — using the file's own documented fallback stack (-apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Segoe UI', Roboto, Helvetica, Arial, sans-serif) exactly as specified in DESIGN.md, not a freehand substitute.
This is the HTML companion to explorations/swiftui/SpotifySignupComparison.swift — same three screens, same tokens, but actually renderable and verified here (headless browser), unlike the SwiftUI file which can't be compiled or previewed in this environment.
